# Codex 额度数据源

本项目只使用官方本地 Codex App Server；官方文档：https://developers.openai.com/codex/app-server/ 。本地发现顺序包括配置的执行文件、PATH、Codex 桌面包资源路径与已注册的 Windows 应用包。

使用 `initialize` / `initialized` 完成协议握手，然后执行只读 `account/read`（不主动刷新 token）与 `account/rateLimits/read`。不启动模型对话、不购买额度、不调用内部网页接口，不读取或上传账号认证文件。协议或产品变化可能导致查询不可用，需要根据官方文档维护。

每个额度窗口显示官方返回的使用比例、剩余比例、窗口长度与重置 Unix 时间（转换为本机时区）。百分比缺失、非数值或越界时显示 N/A，不能把未知当成 0%。仅在官方提供足够数据时显示窗口，不用 Session Token 数量推算订阅额度。

安装并登录官方 Codex 后在管理端查看数据源状态。程序可以独立启动所需 App Server，不要求 Codex 桌面窗口始终打开，但本机 CLI/桌面所带可执行文件必须存在且账号登录有效。

| 状态 | 处理 |
|---|---|
| 未找到 CLI | 安装官方 Codex，或在退出后台后配置本机 codex_executable 路径 |
| 未登录或认证失效 | 在官方 Codex 内完成登录；不要把凭据粘贴进 Dashboard |
| 超时/数据不可用 | 检查 Codex 和网络，其他模块继续运行；下个周期重试 |
| 额度为空 | 如实显示未知，不把它当成免费无限额度 |

刷新默认 5 分钟，订阅额度和 Token 统计是不同概念。项目不保证任何账号类型都支持相同额度字段。对本地/开源客户端的使用应遵守官方产品条款；本说明不授予 OpenAI 产品或商标许可。
