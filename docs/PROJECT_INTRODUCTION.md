# 项目介绍

## 一句话

把闲置 Kindle 变成 Windows 的 USB 有线桌面信息屏：时间、待办、电脑状态与 Codex 额度，全部在本机管理。

## 为什么做这个项目

工作时经常需要反复打开待办、系统监控和额度页面。闲置 Kindle 适合显示低频变化、需要随时看一眼的信息。项目把采集和排版留在 Windows，Kindle 只接收黑白图片、定时显示；一根 USB 线同时负责供电与数据，不增加树莓派或付费云服务。

## 主要特点

- 中文优先：结构化输入事项、时间、地点和优先级，未来事项不会从屏幕上消失。
- 两页分工：工作总览显示近期安排和额度，电脑监控页显示 CPU/GPU/内存。
- 数据真实：传感器或官方额度接口不可用时显示 N/A 和明确状态，不用模拟值填空。
- 有线与本地：USBNetwork + SSH/SCP；SQLite 待办留在本机，管理页只允许本机访问。
- 离线可用：Windows 离线后，仍在运行且有电的 Kindle 客户端继续走时。
- 易维护：Python、FastAPI、Pillow、SQLite 与轻量 shell，没有复杂桌面框架。

## 面向谁

拥有兼容 Kindle、愿意按原维护者资料完成设备准备、使用 Windows 的中文社区用户。当前是社区测试版，首个实测组合为 Paperwhite 3 / 5.16.2.1.1，不是面向所有 Kindle 的即插即用产品。

## 当前边界

不是电脑桌面实时投屏，不追求秒级动画；不提供一键越狱、不分发第三方驱动与固件、不提供额外 Codex 额度。24 小时运行、长期残影、Kindle 重启自动运行和其他机型仍需后续验证。

## 仓库简介建议

Kindle 桌面信息屏：Windows + USB 有线同步，中文待办、电脑状态、Codex 额度与离线时钟。本地运行，无额外付费 API。
